## 怎么用

1. 下载并解压加密包。
2. 通过官方渠道取得解锁码（例如评论「循环」后私信）。
3. 运行 `./unlock.sh`（或 Windows 下 `unlock.ps1`），输入解锁码。
4. 得到 `loop-onion.unlocked.md` 后按文内指令使用。

正版指纹：解锁后正文可见 `GUANGUANJOJO-LOOP-ONION-v1` 与「关关Jojo」。
